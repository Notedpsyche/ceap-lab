01 / TRANSFER THE STATE

What reaches Bob?

Alice’s input is |ψ⟩ = α|0⟩ + β|1⟩. First, quantum channels distribute entanglement. Alice then performs CNOT and Hadamard operations and measures her input and resource half. Two classical bits tell Bob which X/Z corrections to apply to his existing qubit.

Shared entanglement + Bell measurement + 2 classical bits → reconstructed quantum state

The original unknown state is consumed. Without the outcome bits Bob’s unannounced state is maximally mixed in the ideal protocol, so teleportation cannot send information faster than light.

Here the input is prepared after the end-to-end resource becomes ready. Final teleportation sums all physical/readout branches for the receiver’s output density matrix; generation and repeater operation branches are sampled.

02 / CONNECT THE LINKS

Swapping extends entanglement.

A repeater holds one half of each of two adjacent pairs. A Bell measurement on those two local qubits, followed by reported-outcome corrections, creates a longer entangled segment. Both source pairs are consumed. Swapping extends reach; it does not purify the resource.

Alice ═ R₁   R₁ ═ Bob   →   Alice ═════ Bob

Legal swaps join adjacent, non-overlapping intervals on the fixed path. All stored pairs age during operation and communication delays.

03 / QUALITY AT A COST

Purification is a probabilistic operation.

The BBPSSW-style protocol takes two pairs with identical endpoints. Each endpoint applies a local CNOT from its retained qubit to its target qubit. The targets are measured, and their recorded bits are compared. Equal bits accept one retained pair; unequal bits reject both. Recorded-bit errors can cause false acceptance.

The accepted state is computed from its actual quantum branch, then ideally Werner-twirled. This free ideal twirl is an explicit model assumption. Gate errors, memory aging, failed attempts and classical delays remain part of the environment.

For identical ideal Werner inputs: pₐ = F² + ⅔F(1−F) + ⁵⁄₉(1−F)²
F′ = [F² + (1−F)²/9] / pₐ

These formulas are independent checks of the state calculation. They do not replace noisy circuit execution.

04 / EVALUATE THE FUTURE

CEAP chooses an intervention.

J-REPA evaluates each feasible action in cloned estimated environments. Each modeled future executes the candidate first, then the same fixed-threshold continuation. Generation and purification failures count in the expected outcome. CEAP selects the highest utility, breaking ties by time, attempts and stable action order.

U(a) = P̂(qualified | a) − wₜ E[Δt]/deadline − w꜀ E[Δattempts]/budget

Observations contain calibration estimates, pair ages, availability, reported outcomes and remaining resources. Hidden density matrices and true readout bits are reserved for evaluation. The oracle diagnostic is a separate comparator, not an optimal policy or guaranteed bound.

CEAP is deterministic seeded planning in this prototype. No PPO model is trained. The candidate contribution is downstream-aware action selection; research novelty and advantage require further evidence.

05 / MEASURE THE SERVICE

Accuracy and completion are different.

State fidelity is F = ⟨ψ|ρBob|ψ⟩. A qualified request completes before its deadline with fidelity at least the target. Failed requests have no output fidelity. Qualified throughput divides qualified completions by the total simulated duration of successful and failed requests.

Batch experiments cycle through all six Pauli eigenstates. Completion probabilities use 95% Wilson intervals; conditional fidelity, latency, throughput and matched policy differences use seeded bootstrap intervals. Cells with fewer than 30 completions are marked sparse.

Random scenarios match generation streams by edge/attempt and operation streams by resource ancestry wherever events correspond. Different policies can create different events, so matching is not an assertion of identical outcomes.

06 / REPRODUCIBLE CONVENTIONS

What this model assumes.

Gate noise uses Dλ(ρ) = (1−λ)ρ + λ(I/d ⊗ Trtargetρ) on the selected gate qubits. A gate λ is not automatically the same number as average infidelity. Readout ε independently flips each designated recorded bit. Final Alice gates and Bob corrections are ideal; final Bell readout uses ε.

Link quality means Bell overlap. Werner links distribute remaining weight equally across the other Bell states. Phase-flip links mix Φ⁺ and Φ⁻. Damping links apply amplitude damping to one Bell half, with γ calibrated to the selected overlap. They are different physical channels even when overlap agrees.

Memory uses local depolarizing contraction exp(−Δt/T) per qubit; T = 0 selects ideal memory. Elementary pairs age during their acknowledgment delay. Other stored states age during all modeled time, including operation and classical delays. Gates are placed at the operation-completion boundary after aging: an explicit short-gate timing approximation. Classical transport and heralding are idealized and reliable.

The resource budget counts every generation attempt, including failed attempts. Stored-pair discards are explicit. One user step can start a generation attempt without advancing time, so attempts on separate available links overlap. No state is copied to create an auxiliary pair.
